# Seeds Module

Модуль для автоматического заполнения базы данных мок данными при запуске приложения.

## Функциональность

- Автоматическое создание 100 мок пользователей при первом запуске сервера
- Проверка пустоты базы данных перед созданием seeds
- Хеширование паролей с помощью bcrypt
- Генерация разнообразных данных пользователей (имена, города, страны, биографии и т.д.)

## Автоматический запуск

Seeds запускаются автоматически при старте приложения в `main.ts`. Система проверяет, пуста ли база данных, и если да - создает 100 мок пользователей.

## API Endpoints

### POST /seeds/run
Запускает полный процесс создания seeds (100 пользователей).

**Ответ:**
```json
{
  "message": "Seeds completed successfully"
}
```

### POST /seeds/users
Создает 100 мок пользователей.

**Ответ:**
```json
{
  "message": "Mock users created successfully"
}
```

### GET /seeds/status
Проверяет статус базы данных.

**Ответ:**
```json
{
  "isEmpty": true
}
```

### POST /seeds/admin/test
Тестовый endpoint для проверки работы контроллера.

**Ответ:**
```json
{
  "message": "Seeds controller is working",
  "timestamp": "2024-01-01T00:00:00.000Z"
}
```

## Структура мок данных

Каждый созданный пользователь содержит:

- **Основные данные**: username, email, password (хешированный)
- **Личная информация**: firstName, lastName, birthday (18-65 лет)
- **Местоположение**: location (город), country, address
- **Профиль**: bio (случайная биография из 20 вариантов)
- **Аватар**: стандартное изображение по умолчанию

## Пароли

Все мок пользователи создаются с паролем `password123`, который хешируется с помощью bcrypt.

## Логирование

Процесс создания seeds логируется с помощью NestJS Logger:
- Прогресс создания пользователей (каждые 10 пользователей)
- Ошибки при создании отдельных пользователей
- Общий статус завершения операции
